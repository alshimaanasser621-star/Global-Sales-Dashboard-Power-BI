# Adventure Works Sales Analysis

## Project Overview
Sales performance analysis for Adventure Works company
using Power BI with full Data Modeling.

## Tools Used
- Power BI Desktop
- Data Modeling (Star Schema)


## Data Model
- Facts Sales (Fact Table)
- Dim Product, Dim Region, Dim Reseller
- Dim Sales Person Key
- Dim Sales Person Region (Bridge Table)
- Dim Targets

## Key Questions Answered
- What are the top regions by sales?
- Which resellers generate the most revenue?
- How do actual sales compare to targets?
- What is the best-selling product category?

## Key Insights
- Southwest is the top region with $18M
- Bikes dominate with $64M in sales
- 2019 was the peak year with $32M
